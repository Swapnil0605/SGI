# Surannavar Group of Institutions - Official Website

A high-performance modern web application for **Surannavar Group of Institutions (SGI), Belagavi**, affiliated with Rajiv Gandhi University of Health Sciences (RGUHS) and backed by Surannavar Superspeciality Hospital.

Designed following the prestige and editorial aesthetics of **The University of Sydney**, tailored to the Surannavar healthcare ecosystem.

---

## 🚀 Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | React.js (v18) |
| **Build Tool** | Vite |
| **Language** | JavaScript (ES Modules) |
| **Styling** | Modern CSS3 (Custom Design Tokens, Responsive Grid, Glassmorphism) |
| **Typography** | Apercu / Space Grotesk / DM Sans (Sydney University Brand Standard) |
| **Animations** | GSAP + ScrollTrigger |
| **3D Graphics** | Three.js / React Three Fiber / Drei |
| **Icons** | Lucide React |

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Visit `http://localhost:3000/` or `http://localhost:3001/` in your browser.

### 3. Build for Production
```bash
npm run build
```
